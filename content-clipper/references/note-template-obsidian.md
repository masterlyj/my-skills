# Obsidian 学习笔记模板（默认）

**这是默认笔记格式。** 主 SKILL.md 步骤 5 默认输出本模板的 Obsidian 学习笔记：
以主旨为纲、按知识逻辑展开、可回头复习，并留下来源证据。

> **本文件只管区块结构与语法**（callout 写法、`assets/` 链接、索引格式）。正文写到什么
> 程度才算讲懂，规则在 `references/learning-note-writing.md`；改讲解质量时改那一份，
> 不要在这里重复同一规则。

> 若明确不需要 Obsidian 语法（要在飞书/Notion 等平台渲染），把 callout 降级为
> 标准引用块、把双链换成标准 Markdown 链接即可，其余结构不变。

---

## 语法校验（Obsidian callout）

写 callout 前确认这几条，写错会导致渲染失败：

| 规则 | 说明 |
|------|------|
| 折叠标记 | `> [!type]-` 默认折叠；`> [!type]+` 默认展开；不能省掉 `>` |
| 块内每一行 | 都必须以 `>` 开头，**包括空行**（写一个单独的 `>`） |
| callout 内的小标题 | **本模板用粗体小标题**（如 `> **关键要点：**`）保持紧凑 |
| 类型名 | 常用 `tip` / `info` / `warning` / `note`，须小写 |
| 嵌套列表 | callout 内的 `-` 列表行前面同样要加 `>` |

**正确示例**：

```markdown
> [!tip]- 💡 补充说明
> 这里是补充正文，可以有多行。
>
> **关键要点：**
> - 要点一
> - 要点二
```

**错误示例**（缺少 `>`，折叠块会断掉）：

```markdown
> [!tip]- 💡 补充说明
这里是补充正文
```

> **三层信息**（正文 / 补充 / 来源，判据见 `references/learning-note-writing.md`）：
> 正文主线保持可见；callout 用于**核对用**细节（详细配置、全量成绩表、奖励系数、旧稿
> 纠错记录）与来源附件；**影响可信度的待核实/待补全项默认不折叠**，用 `> [!warning]`
> 或 `> [!warning]+`；仅轻微的补充说明可折叠。移出正文的细节要在正文留**可达指针**。

## 学习笔记模板（默认）

```markdown
---

  - {{标签1}}
  - {{标签2}}
---

# {{一句话标题：材料在讲什么，判断有材料支撑；避免「XX视频的总结」式纯描述}}

{{主旨：普通段落。先给具体问题与为什么值得关心，再给结论；不放 callout。}}

## {{按知识逻辑划分的小节一}}

{{讲解主线：先用连续文字讲通「在解决什么问题 / 怎么起作用 / 依据是什么 / 能不能得出
这个结论」，再补理解主线必需的数据与图。概念首次出现时先用一句话说明它做什么、在这份
材料里起什么作用，再给术语。不要每节套同一问答模板；教学例子/类比要标出来；材料没说
原因的因果不虚构，就写「材料没有说明原因」。}}

{{可选：表格。用**最小对照**支撑主线结论（一对对照够说明趋势就不搬全榜）；只用于已经解释过的维度做横向比较，不代替第一次讲概念；全量成绩表放「可选查阅」。}}

{{可选：关键图。图注用**可见文字**写出这张图说明了什么、支撑什么（材料能证明时才写「证明」）。}}

{{同上。必要时用代码块提炼关键思路。}}

## 📚 可选查阅

> [!note]- {{补充标题：详细配置 / 全量成绩表 / 奖励系数 / 旧稿纠错记录}}

## 🧭 回顾要点

---

> [!warning] ⚠️ 待核实
> {{转录与画面/上下文不一致、或来源不明的点；影响可信度，默认不折叠；没有则删除本节}}

> [!info]- 📎 来源与附件
```

## 来源证据目录

正文用**相对链接**引用 `clips/<平台>/assets/<笔记文件名不含 .md>/` 下的证据
（路径含空格时用 `<>` 包裹，如 `(<assets/2026-09-20 标题/fig-01.png>)`）：

| 文件 | 内容 | 何时建 |
|------|------|--------|
| `source.txt` | 本次**实际使用**的平台字幕，或**带时间戳**的转录原文 | 有素材才建 |
| `visual-notes.md` | **实际支撑本次笔记**的视觉解读片段，并具体标注对应的来源图片 | 有画面解读才建 |
| 关键图 | **选出的少量关键图**，正文配图注（可见文字，不能只有 `alt`）写出这张图说明了什么、支撑什么 | 没有就不凑数 |

- `visual-notes.md` 里**用到的图片必须一并保留并在正文链接**，不能只留文本却删掉引用图。
- **原始文本与修订笔记分开**：`source.txt` 保留原始记录，**不修改**；术语修正在笔记正文里
  **记录依据与位置**（如"第 3 张截图 / 转录 02:14"），修正不冒充原话。
- 证据要**关联到具体位置或截图文件**，不能只给一个来源总链接。

## 索引文件模板（Obsidian 双链）

```markdown
# 📋 {{平台}}收藏索引

> 按日期倒序。Ctrl+F 搜标签即可定位。

- [[{{日期}} {{短标题}}]] — {{核心洞察}}
```

- 双链 `[[...]]` 的**目标必须准确**，对应真实存在的笔记文件名。
- **同一内容**的已有索引条目**更新而不重复**；**不同内容即使同一天也分别保留**。
- 笔记文件名冲突时，按**可辨识的来源 ID**（如 BV 号、帖子 ID）消歧；**用户手写的内容不覆盖**。
- `[[...]]` **只在 Obsidian 中有效**；要跨平台使用时改成标准 Markdown 链接
  `- [标题](文件名.md)`。

## 关键约束

1. 标题点明材料讲什么，判断**需材料支撑**，不必夸大；避免「XX视频的总结」式纯描述。
2. 每篇笔记开头写 `tags` 属性。
3. 区块顺序：**正文主线 → 可选查阅 → 回顾要点 → 来源附件**；四类区块**按需出现**，没有增量的
   标题省略或合并，**不固定数量**；讲解质量规则见 `references/learning-note-writing.md`，本文件不重复。
4. 主线（主旨、展开讲解、回顾要点）**正文可见**；待核实/待补全**默认不折叠**；移出
   正文的细节要在正文留**可达指针**。
5. **逐字稿作附件**（`source.txt`），不进笔记正文，与笔记分离。
6. 纯观点内容**标注归属**，不当科学定论；外部事实**可核来源**，不确定不猜。
7. 附件用**相对链接**（含空格用 `<>`），**链接必须实际存在**；没有证据就不建、不摆占位。
8. 无法确定的写「待核实」或省略；来源可信度规则见 `SKILL.md` 步骤 5.5。
