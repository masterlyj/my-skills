# Obsidian 笔记模板（可选）

**这是可选格式，默认不使用。** 主 SKILL.md 步骤 5 默认输出中性 Markdown
（标准引用块 + 标准链接），可在飞书/Notion 等平台正常渲染。

只有明确要在 Obsidian 里使用折叠效果时，才改用下面的模板。

---

## 语法校验（Obsidian callout）

改用前请确认这几条，写错会导致折叠块渲染失败：

| 规则 | 说明 |
|------|------|
| 折叠标记 | `> [!type]-` 默认折叠；`> [!type]+` 默认展开；不能省掉 `>` |
| 块内每一行 | 都必须以 `>` 开头，包括空行（写一个单独的 `>`） |
| 不支持标题 | callout 内不能用 `##` 标题，会中断折叠块，改用粗体行 |
| 类型名 | 常用 `tip` / `info` / `warning` / `note`，须小写 |
| 嵌套列表 | callout 内的 `-` 列表行前面同样要加 `>` |

**正确示例**：

```markdown
> [!tip]- 💡 总结
> 这里是总结正文，可以有多行。
>
> **关键要点：**
> - 要点一
> - 要点二
```

**错误示例**（缺少 `>`，折叠块会断掉）：

```markdown
> [!tip]- 💡 总结
这里是总结正文
```

## 有字幕/转录时的模板

```markdown
# {{一句话核心洞察，是判断而非描述}}

{{核心论点，3-6 句话。给出核心判断、关键论据与主要结论。}}

> [!tip]- 💡 总结
> {{展开写核心论点。若涉及多个论点，逐一列出。}}
>
> **关键要点：**
> - {{要点一}}
> - {{要点二}}
> - {{要点三}}
> - {{至少 3-5 个；信息量大可更多}}
>
> **值得深挖吗：** {{是/否}}。{{一句话理由}}

---

> [!tip]- 📝 完整文本（逐字记录）
> 来源：{{平台字幕 / 本地转录 / 无字幕}}
> 共 {{N}} 段，以下为完整记录。
>
> {{带时间戳的完整内容，每行前加 >}}

---

> [!info]- 🖼️ 画面解读
> {{关键帧理解结果：本页主题、图示关系、要点}}
> {{没有画面理解时删除本节}}

---

> [!info]- 笔记属性
> - **来源**: {{平台}} · {{作者}}
> - **链接**: {{原始链接}}
> - **日期**: {{YYYY-MM-DD}}
> - **时长/类型**: {{时长或图文}}
> - **互动**: {{播放/点赞/收藏等}}
> - **字幕来源**: {{平台字幕 / 本地转录 / 无字幕}}
```

## 无字幕时的模板

```markdown
# {{基于标题与描述提炼的核心洞察}}

> [!tip]- 💡 总结
> {{从描述与画面解读提炼。注意：部分内容描述为空或极短，
> 此时核心洞察只能基于标题、标签与画面推断。}}
>
> **关键要点：**
> - {{要点一}}
> - {{要点二}}

> [!info]- 🖼️ 画面解读
> {{这是无字幕时的主要信息来源，务必展开}}

> [!warning]- 无字幕
> 该内容无可用字幕，以上基于标题、描述、标签与画面画面解读生成。

> [!info]- 笔记属性
> - **来源**: {{平台}} · {{作者}}
> - **链接**: {{原始链接}}
> - **日期**: {{YYYY-MM-DD}}
```

## 索引文件模板（Obsidian 双链）

```markdown
# 📋 {{平台}}收藏索引

> 按日期倒序。Ctrl+F 搜标签即可定位。

- [[{{YYYY-MM-DD}} {{短标题}}]] — {{核心洞察}} `#标签A #标签B`
```

> `[[...]]` 是 Obsidian 双链语法，**只在 Obsidian 中有效**。
> 若笔记要在其他平台使用，索引改为标准 Markdown 链接 `- [标题](文件名.md)`。

---

## 关键约束（无论用哪种模板）

1. **标题必须是洞察/判断**，不能是「XX视频的总结」
2. **总结至少 3-6 句 + 3-5 个要点**；信息量大的内容可更多
3. **完整文本绝不删减**（选择保留转录时）
4. **笔记属性必须含可点击的原始链接**
5. **折叠区域外的可见内容不超过 6 行**（便于快速扫读）
